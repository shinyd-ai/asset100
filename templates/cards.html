키워드 카테고리 삭제

거래 내역과 카테고리 규칙에서 사용할 카테고리 목록입니다.

카테고리명 삭제
모바일 문자(SMS) / 앱 푸시 자동 연동 설정

안드로이드 스마트폰에 자동화 앱(MacroDroid, SmsForwarder 등)을 설치하면, 현대 / 삼성 / 롯데 / 하나카드 결제 문자가 올 때마다 즉시 가계부 DB에 자동 기록됩니다.

※ Render 환경변수 WEBHOOK_API_KEY로 원하는 비밀키로 변경 가능합니다.
MacroDroid 간편 설정법 (3분)
  1. 플레이스토어에서 MacroDroid 앱 설치
  2. 매크로 추가 클릭
  3. 트리거(+): 메시지 → SMS 수신 → 내용 포함: 승인, 카드, 결제 (또는 기기 이벤트 → 알림 수신에서 카드사 앱 선택)
  4. 작업(+): 웹 → HTTP 요청
    • 요청 방식: POST
    • URL: https://asset100.onrender.com/api/card-tx/webhook
    • 콘텐츠 유형: application/json
    • 요청 본문(Body): 
      {"message": "{sms_message}", "api_key": "asset100_secret_2026"}
      (알림 푸시인 경우 {notification_text} 또는 {notification_big_text})
  5. 매크로 저장 완료! 이제 카드를 결제하면 자동으로 가계부에 실시간 등록됩니다.
